Run Docker on macOS with Colima

在企业环境中，Docker Desktop 可能受到授权、策略或系统配置限制，导致 Docker daemon 无法正常启动。即使日常的镜像构建通常由 CI/CD 流水线完成，本地开发、调试和学习时仍然需要一个可用的 Docker runtime。 本文介绍如何使用 Colima 在 macOS 上运行 Docker。Colima 基于 Lima 启动轻量级 Linux 虚拟机，并在虚拟机中运行 Docker daemon；macOS 上的 Docker CLI 则通过 Colima 访问这个 daemon。 Install 首先安装 Docker CLI、Colima 和 Docker Compose： brew install docker colima docker-compose 这里安装的是 Docker 客户端，而不是 Docker Desktop。Colima 启动后会自动配置 Docker context，通常不需要额外设置 DOCKER_HOST。 Start Colima 使用 Docker runtime 启动 Colima： colima start --runtime docker --cpu 4 --memory 6 --disk 60 参数分别表示 CPU 核数、内存大小和虚拟磁盘大小。第一次启动时，Colima 会创建并初始化虚拟机，可能需要一些时间。 启动完成后，先确认 Docker daemon 是否可用： ...
