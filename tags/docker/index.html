Run Docker on macOS with Rancher Desktop or Colima

在企业环境中，Docker Desktop 可能受到授权、策略或系统配置限制，导致 Docker daemon 无法正常启动。即使日常的镜像构建通常由 CI/CD 流水线完成，本地开发、调试和学习时仍然需要一个可用的 Docker runtime。 本文介绍两种在 macOS 上运行 Docker 的方案： Rancher Desktop：提供图形界面，可同时管理容器运行时和本地 Kubernetes，适合希望开箱即用、可视化配置的用户。 Colima：基于 Lima 的轻量命令行方案，适合偏好 CLI、希望控制资源占用的用户。 两者都会在 Linux 虚拟机中运行容器服务，并让 macOS 上的 Docker CLI 连接该服务。日常只需要使用 Docker 时，二选一即可，不建议同时启动，避免 Docker context 和资源占用相互干扰。 Choose a Runtime 方案 更适合 Docker CLI Kubernetes 操作方式 Rancher Desktop 希望通过界面管理配置和状态 选择 Moby 后可用 内置，可关闭 GUI + rdctl Colima 偏好轻量、脚本化的本地环境 可用 可选 CLI 如果希望获得接近 Docker Desktop 的桌面体验，可以优先选择 Rancher Desktop；如果只需要一个轻量 Docker daemon，可以继续使用 Colima。 Rancher Desktop Rancher Desktop 是一个开源桌面应用，支持 macOS 的 Intel 和 Apple Silicon 设备。它提供两种容器引擎： ...
